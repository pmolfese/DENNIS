Decomposition Stacks

Automator's shape: steps stack top to bottom, each one feeding the notch below it. The shelf is a horizontal strip of icons you drag down into a stack. Streams sit side by side in fixed levels, so everything on row 2 is a second-stage decomposition no matter which stream it belongs to — and a stream can borrow its input from a card in the lane next door.

Levels carry meaning

Row 1 is always the source tensor. Row 2 is a first decomposition of it, row 3 a decomposition of those scores. Reading across a row compares like with like: temporal-first versus spatial-first on the same group, side by side.

Stacking is the wiring

A card takes the card above it as input — no wires to draw for the common case. The only explicit link is a cross-stream input, drawn as one arrow, for when a lane branches off something in the lane beside it.

Branching

"Branch" on any card opens a new stream to its right, already fed by that card and starting at the next level down. That is how one temporal PCA feeds both a spatial decomposition and an Infomax run without duplicating the first step.

Same engine underneath

Every decomposition card is one PCACore.doPCA: matrix (COV/COR/SCP), decomposition (SVD/NIPALS), loading, rotation, factor count — with the card's kind choosing the PCAMode used to unfold the EPTensor. Today's TwoStepPCA is a two-card stack.
